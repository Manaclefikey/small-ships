## About

Vanilla boats are a joke and everyone knows it. Small Ships adds cogs, briggs, galleys and drakkars — real vessels with sails you raise and lower, cargo holds, cannons, multiple passenger seats and handling that responds to wind and hull type.

---

## Features

- Several ship classes from rowboats to multi-masted briggs
- Raisable sails, steering and wind-influenced handling
- Cargo holds with real inventory capacity
- Mountable cannons for naval combat
- Multi-passenger seating for crewed voyages

## Installation

1. **Download** the JAR matching your Minecraft version from the table above.
2. **Install a mod loader** — Forge, Fabric or NeoForge for your exact game version.
3. **Place the `.jar`** into your `.minecraft/mods/` folder (create it if it is missing).
4. **Launch** Minecraft using the modded profile.
5. Verify **Small Ships** appears in the in-game mods list.

> **Tip:** if the game crashes on startup, you almost certainly mixed a Legacy JAR with a Modern
> Minecraft version, or are missing a required dependency. Check `latest.log` first.

## FAQ

**Q: Can ships carry chests?**
A: Larger classes have built-in cargo inventories.

**Q: Do cannons work in multiplayer?**
A: Yes, naval PvP is supported.

**Q: Can ships be damaged or sunk?**
A: Yes — hull damage is tracked and ships can be repaired.

**Q: Is it safe to add to an existing world?**
A: Yes in most cases — back the save up first, as you should with any mod addition.

**Q: Can I use it in a public modpack?**
A: Yes. Both builds are modpack-ready and require no additional setup.
